# Background

`guacamol_celecoxib_rediscovery_demo` is a GuacaMol-derived rediscovery task.
It uses a fixed-length SELFIES token search space and scores decoded molecules by ECFP4 Tanimoto similarity to Celecoxib.

The task mirrors GuacaMol's Celecoxib rediscovery objective while exposing an ask/tell-friendly black-box optimization interface.
