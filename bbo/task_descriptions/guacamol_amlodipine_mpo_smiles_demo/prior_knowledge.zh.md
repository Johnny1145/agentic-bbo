# 领域先验

这是 GuacaMol 中与药物相关的 multi-property objective benchmark 之一。benchmark 定义的参考分子是 amlodipine。

score 是 amlodipine similarity 和 total-ring-count 项的标量化组合。PABLO 将 Amlodipine 任务作为 Task Awareness 的示例，其自然语言目标是“maximize similarity to amlodipine while having exactly 3 total rings”。这是 task-aware 设置，不是严格黑盒设置。
