# 领域先验知识

- 从 x 到 y 的映射不是对坐标提案的直接几何评估。evaluator 会先把 x 解码为合法的宏单元布局。
- 在 MGO 解码中，连接模块面积更大的宏单元会更早放置，因此高连接度或高影响宏单元的坐标可能对 y 有更强影响。
- 对每个宏单元，decoder 会优先选择增量 HPWL 更小的合法网格位置。如果多个网格具有相同的增量 HPWL，则选择最接近候选坐标的网格。
- 由于最终布局位于网格上，x 的小变化在某些区域可能没有效果，但在解码边界附近可能导致离散跳变。
- HPWL 衡量的是线长代理质量，不是最终 routed PPA。较低的 y 是有用信号，但不能保证时序、拥塞或功耗最优。
